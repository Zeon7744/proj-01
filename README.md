## 🛠️ 核心功能

| 模块 | 功能 |
|------|------|
| **任务管理** | 任务创建、分配、追踪、统计 |
| **FinAgent** | 金融数据获取、分析、可视化 |
| **量化策略** | 回测引擎、策略优化、绩效分析 |
| **报表生成** | HTML/PDF 报告导出 |
